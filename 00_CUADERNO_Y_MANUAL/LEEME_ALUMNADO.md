# Kit del alumnado

Este material acompaña el seminario «Arquitectura de Datos en Python y Ciencia Abierta». El caso de la naranja y el plátano es una **simulación docente**: no contiene participantes reales, no valida señales de tráfico y no prueba una asociación universal.

## Durante la sesión

- Imprima `CUADERNO_ESTUDIANTE_SEMINARIO_2026.pdf` al 100 %.
- Use `CUADERNO_ESTUDIANTE_SEMINARIO_2026.docx` si desea completar las fichas desde el ordenador.
- Para la dinámica inicial, imprima `FICHA_JUEGO_COORDINACION_A4_EDITABLE.pdf`.
- Para diseñar un estudio propio, use `CANVAS_DISENO_ESTUDIO_A4_EDITABLE.pdf`.
- Consulte `MANUAL_ALUMNO_FINAL.pdf` después de la clase; explica el recorrido sin exigir que memorice Python.

## Para repetir el análisis

1. Abra `../05_ANALISIS/laboratorio_velocidad_frutas.html` si solo quiere leer el código y sus salidas.
2. Abra el archivo `.ipynb` en Jupyter si quiere ejecutar o cambiar una celda.
3. Cambios seguros: una ruta, un nombre de grupo, el color de una figura o una agrupación sencilla.
4. No cambie la regla `< 2.0`, el resultado primario ni el test confirmatorio sin registrar una desviación.

## Regla de privacidad

La carpeta pública no contiene el mapa de bonificaciones ni identificadores brutos. Si adapta el proyecto, revise texto abierto, rutas, secretos y variables de plataforma antes de cualquier `git push`.

El manifiesto SHA-256 permite comprobar los archivos del kit.
