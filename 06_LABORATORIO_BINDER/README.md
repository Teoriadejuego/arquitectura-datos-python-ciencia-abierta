# Laboratorio ejecutable en Binder

Este directorio contiene una actividad autocontenida del seminario **Arquitectura de Datos en Python y Ciencia Abierta**.

[![Abrir en Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/Teoriadejuego/arquitectura-datos-python-ciencia-abierta/main?urlpath=lab/tree/06_LABORATORIO_BINDER/LABORATORIO_PYTHON_VELOCIDAD_FRUTAS_SIMPLE.ipynb)

## Uso

1. Pulsa **Abrir en Binder**.
2. Espera a que se construya el entorno; la primera apertura puede tardar varios minutos.
3. Abre el cuaderno si JupyterLab no lo muestra automáticamente.
4. Ejecuta cada celda con **Mayús + Intro**.
5. Descarga tu copia antes de cerrar si quieres conservar cambios.

## Contenido

- `LABORATORIO_PYTHON_VELOCIDAD_FRUTAS_SIMPLE.ipynb`: recorrido guiado.
- `DATOS_FICTICIOS_PROLIFIC_VELOCIDAD_FRUTAS.csv`: 500 registros sintéticos.

Los datos no proceden de participantes reales. Los campos con nombres de plataforma están vacíos. La sesión de Binder es temporal y no debe utilizarse para introducir secretos ni datos personales.
